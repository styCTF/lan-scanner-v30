📖 使用说明 ▼
  1. 下载 rar 文件后解压，得到 lan_scanner.py 和 run.bat
  2. 直接双击 run.bat 进入命令行窗口，选择网卡进行扫描
  3. 等待扫描完成，查看同网段内在线设备的 IP 和 MAC 地址
⚠ 注意事项：
  • 如有虚拟机，请注意区分虚拟网卡和物理机网卡
  • 如果交换机开启了端口隔离，可能导致扫不到其他设备

📝 如何更改背景：
  1. 在上方标签页中选择 纯色、渐变 或 图片
  2. 纯色：点击预设色块或使用取色器选择喜欢的颜色，页面背景立即生效
  3. 渐变：选择预设渐变风格，或自定义起止颜色和角度
  4. 图片：粘贴在线图片链接并点击"应用"，或上传本地图片文件
  5. 所有设置 自动保存 到浏览器，下次打开页面无需重新设置
  6. 点击"重置背景"可恢复默认的深蓝渐变外观
